Manual de usabilidad

Como usar el CRM en una reunion o en la operacion diaria

1. Cargar leads Usa Nuevo lead para registrar canal, busqueda, zona, presupuesto, pais, nacionalidad y tiempo de compra.
2. Segmentar Usa Canal para separar WhatsApp, Facebook, Instagram, X, Recomendaciones y Otros. El Dashboard muestra el peso de cada origen.
3. Gestionar pipeline En Pipeline podes arrastrar tarjetas entre columnas o usar las flechas de avance y retroceso.
4. Registrar contacto Desde la ficha del cliente agrega una llamada, WhatsApp, reunion o email. Luego se ve en Historial comercial.
5. Clientes extranjeros El pais es un campo formal. Si no es Paraguay, el CRM lo marca como extranjero y lo contabiliza en metricas.
6. Exportar Exportar genera un CSV con los leads filtrados. Para servidor, la evolucion recomendada es Node.js + PostgreSQL + Prisma en Railway.
